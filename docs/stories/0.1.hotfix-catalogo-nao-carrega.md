## Problema
Em https://americaindustria.com.br/catalogo-2026.html o visualizador fica em branco ("1 / --").

## Causa (diagnóstico no Chrome, 2026-11-25)
- Console: `TypeError: Cannot read properties of null (reading 'addEventListener')` em `catalogo-*.js`.
- O botão Imprimir (`#print-pdf`) foi removido do HTML no commit `443d179` (04/02/2026), mas `src/catalogo.js`
  ainda chamava `printBtn.addEventListener(...)`. A exceção interrompe o módulo antes do `initPDF()` → o PDF nunca é pedido.
- **Não** era o tamanho do PDF: o servidor aceita range requests (206) e serve os 48 MB em ~3,5 s.
- Achado extra: `tailwind.config.js` não lia `catalogo-2026.html`, então classes usadas só nessa página não eram geradas.
